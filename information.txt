=== VisionGuard Enterprise — Face Recognition Setup & Usage Guide ===

1. Create and Activate Virtual Environment:
   - Create:     python -m venv .venv
   - Activate:   .venv\Scripts\activate
   - Deactivate: deactivate

2. Install Dependencies:
   - pip install -r requirements.txt
   (Installs opencv-contrib-python, pillow, and numpy)

3. Launch Modern Enterprise GUI Application (Recommended):
   - python app.py
   Features:
   - Simultaneous multi-person live face detection & recognition
   - Built-in User Enrollment & Profile Manager (ID, Name, Age, Department, Role)
   - One-click LBPH Model Training
   - Real-time Attendance / Audit Logging with CSV Export
   - Adjustable LBPH Distance Threshold & Camera Settings

4. Standalone CLI Scripts (Optional):
   - Enroll a user:                  python data_creater.py
   - Train the LBPH model:           python trainer.py
   - Run simultaneous recognition:   python detect.py
